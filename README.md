# 📺 KumoutaSub

AT-X 日语字幕与云歌字幕组（Kumouta Subtitles）作品存档。

---

## 📂 仓库结构

```text
AT-X/
├── 2026/
│   ├── Winter/
│   ├── Spring/
│   ├── Summer/
│   └── Autumn/

Fansub/
├── 2026/
│   ├── Winter/
│   ├── Spring/
│   ├── Summer/
│   └── Autumn/
```

### 📺 AT-X

存放日本电视台 **AT-X** 播出的原始日语字幕（ASS）。

目录按照 **年份 → 季度 → 动画作品** 进行分类，方便查找与归档。

### 🌸 Fansub

存放 **云歌字幕组（Kumouta Subtitles）** 制作的字幕作品。

目录同样按照 **年份 → 季度 → 动画作品** 进行分类，部分作品可能包含字体、工程文件等相关资源。
